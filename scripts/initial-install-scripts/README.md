# New server

**DON'T RUN ON THE HOST REPLICA!**

Congrats on the new server. Copy this folder to the root on your new server.

*Setup access to github*
*Clone dotfiles* (git clone `git@github.com:sukkergris/devcontainer-dotfiles.git`)

Run: `stow -t *`

*Clone host repos* (git clone `git@github.com:sukkergris/site-fleet-cms-server.git app`)
